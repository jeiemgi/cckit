The area pages explain why a team does something and walk you through it. Reference pages are for
the moment after that: you know what you want and need the exact flag, config key or file name.
They are written to be looked up, not read top to bottom.

If you are new, start at [Software](/software/) and come back here when a guide sends you. Search
finds every page listed below.
