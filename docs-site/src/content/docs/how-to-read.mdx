This is a visual guide. Coloured **tags** tell you *how* a thing is used before you read a word of it.

A tag sits next to a heading or a name and tells you how that thing is triggered. Its colour means
the same on every page.

## Two tracks

The switch beside the site title moves between the site's two tracks.

| Track | For | Accent | Starts at |
| --- | --- | --- | --- |
| **Software** | developers who drive cckit from a terminal or from Claude Code | blue | [Quickstart](/getting-started/) |
| **Marketing** | marketing teams who work by talking to Claude and never open a terminal | red | [What cckit does for a marketing team](/marketing/) |

Each track has its own sidebar. The Software sidebar lists the pages most readers need, in four
groups named after the job you are doing: **Start**, **Ship one issue**, **Ship many at once** and
**Look it up**. Every other Software page is one click away on [All guides](/guides/) and
[All tutorials](/tutorials/), and search covers all of them.

The Marketing pages are also in Spanish: use the language picker in the top bar of any Marketing
page. Software pages are in English only.

## How to use them

- A page tagged <Tag kind="flow" /> describes a process you can run from start to finish.
- A name tagged <Tag kind="command" /> is something you type in a terminal.
- A name tagged <Tag kind="skill" /> is something you run inside Claude Code with a `/`.
- A name tagged <Tag kind="conversational" /> happens just by asking Claude in plain words.

You don't have to read top to bottom. Scan for the tag that matches what you want to do, and start
there.
