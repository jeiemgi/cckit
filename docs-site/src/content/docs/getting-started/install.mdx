Every step of the process is one `cckit` command, and every one of them talks to GitHub. So before
a project can be set up, the machine needs two things: the command itself, and a GitHub sign-in it
can use. This page gets you both and has cckit check its own work.

Each step starts with the sentence you say to your agent in the chat. Below it is the command your
agent runs for that sentence, and what it printed, pasted from a real run on the Bakery site, the
example project of these guides. You can type any command yourself.

**What you will have at the end:** `cckit` answers in any folder, `cckit doctor` reports nothing
missing, and `gh` is signed in to GitHub. No repository has been touched yet.

## Steps

## 1. Confirm your platform is supported

| Platform | Supported |
| -------- | --------- |
| macOS    | Yes, native |
| Linux    | Yes, native |
| Windows  | Yes, through WSL or Git Bash (not native cmd or PowerShell) |

The command-line tools it needs are checked for you in step 4.

## 4. Let the doctor check the rest

You need `bash`, `git`, [`gh`](https://cli.github.com/) (the GitHub command-line tool), `jq` (a JSON
reader) and `perl`. `cckit doctor` finds what is missing and, **when you run it in a terminal, asks
before installing anything**.

<Chat
  title="checking the Bakery computer for missing tools"
  say="Check that this computer has everything cckit needs, and tell me what is missing."
  ran="cckit doctor"
  output={[
    "  ⡶ / claude-kit  kit-doctor",
    "  onboarding preflight [dry-run] [no-install]",
    "  - report-only — no terminal and no --fix, so nothing is installed and no file is written. To install: cckit doctor --fix",
    "",
    "  Tier 0 — bootstrap",
    "  ✓  Homebrew                     Homebrew 7.0.13-97-g53c5856",
    "",
    "  Tier 1 — hard deps",
    "  ✓  git                          2.55.0",
    "  ✓  gh                           2.104.0 (Projects v2 ok)",
    "  ✓  jq                           jq-1.8.2",
    "  ✓  perl                         is",
    "…",
    "  Summary",
    "       18 checked ok",
  ]}
  means="Run with no terminal to ask in, the doctor only reports: it installs nothing and writes no file. It says so on its second line."
>
  Nothing is missing: `git`, `gh`, `jq` and `perl` are all present, and 18 checks passed. Because I
  ran this without a terminal, I installed nothing.
</Chat>

Run in a terminal, the doctor asks before it installs each missing piece (Homebrew, `gh`, `jq`, …).
Say yes and it installs it. Say no and it prints the exact commands to run yourself. Run where there
is no terminal to ask in (from an agent, a script, CI) it installs nothing and writes no file. To
skip the question, use `--fix`:

```bash title="Install the missing pieces without the prompt"
cckit doctor --fix
```

## 5. Sign in to GitHub

<Chat
  title="signing in to GitHub for the Bakery site"
  say="Sign this computer in to GitHub."
  ran="gh auth login"
  means="This one needs you. The command asks you questions and opens a browser to confirm the sign-in."
>
  I started the sign-in, but I cannot finish it for you: it waits on a code and a browser window.
  Complete it in your terminal, then I will run the doctor again.
</Chat>

<Aside type="tip" title="New to the terminal? Start here">
The terminal is the text window where you type commands. [`gh`](https://cli.github.com/) is GitHub's
official command-line tool. Run `cckit doctor`, approve the prompt, and it installs `gh` (and anything
else missing) for you; then `gh auth login` signs you in.
</Aside>
