Connect your project to Supabase

Supabase keeps your app's information (accounts, saved items, orders) on its servers. Your project already has the code that talks to it. What is missing is two values that only you can get: the address of your Supabase project, and a key. This page shows where each one is and where it goes.

It takes about five minutes. A free account is enough.

Last verified: 2026-11-12 against the Supabase documentation (links at the bottom). If the Supabase website looks different from these steps, the documentation link is the current source.

The steps

  1. Open Supabase and sign in

    Go to https://supabase.com/dashboard/new/_. Sign in, or create a free account first.

  2. Create the project

    Fill in the new-project form: a project name, a database password, and the region closest to your users. Save the database password in a password manager; it is not one of the two values below. Create the project and wait until it is ready.

  3. Click “Connect”

    On the project page, click Connect at the top. The dialog shows the Project URL and the publishable key for the framework you select. Choose Next.js.

  4. Copy the Project URL into the file

    Open the file .env.local in your project folder. Replace the placeholder after NEXT_PUBLIC_SUPABASE_URL= with the Project URL.

  5. Copy the publishable key into the file

    The publishable key starts with sb_publishable_. Replace the placeholder after NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY= with it. Every key is also listed under Settings > API Keys.

  6. Leave the secret keys where they are

    Do not put a secret key (it starts with sb_secret_) or the legacy service_role key in this file. Those are for servers only and must never reach a browser.

  7. Save, then start the app again

    Save the file. Stop the app if it is running and start it again with pnpm dev, so it reads the new values.

What goes where

Name in the fileWhat it isWhere to find it
NEXT_PUBLIC_SUPABASE_URLThe address of your Supabase project (Project URL)Your project > Connect
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEYThe publishable key, starting with sb_publishable_Your project > Connect, or Settings > API Keys

What the file looks like when you are done

The file is .env.local, in the top folder of your project. The parts after each = are yours; these are stand-ins.

NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
The file stays on your computer. Git ignores .env.local, so it is never uploaded to GitHub. You type the values in yourself: cckit does not read them, print them or send them anywhere.
Never paste a key into a chat, an issue, a commit or a screenshot. If a secret key leaks, create a new one under Settings > API Keys and delete the old one.

Using it in your code

Your project has two small files. Use lib/supabase/client.ts in parts of the app that run in the browser, and lib/supabase/server.ts in parts that run on the server.

import { createClient } from "@/lib/supabase/server";

export default async function Page() {
  const supabase = await createClient();
  const { data } = await supabase.from("notes").select();
  return <pre>{JSON.stringify(data, null, 2)}</pre>;
}
