# Patterns of a generic generated page

Pick at least four of these for the brief's "Refuses to look like", and check each one in the
self-review. They are the patterns an agent produces when it is asked for a page and given no
direction. A pattern is listed by what a person sees, so it can be checked by looking.

## Structure

- A centred hero: headline, one line of grey subtext, two buttons side by side.
- Three cards in a row, each with an icon in a rounded square, a three-word title and two lines.
- The section order hero → three features → testimonials → pricing → call to action → footer,
  whatever the page is for.
- Every section the same height, the same padding and the same centred column.
- Cards nested inside cards.
- A "Trusted by" row of grey logos for companies that were never named.

## Type

- One sans-serif family (Inter, or the framework's default) for every piece of text.
- A serif headline over a sans-serif body, chosen for "elegance" and not for the content.
- Headings that differ from body text only in size.
- Centre-aligned paragraphs longer than three lines.

## Colour

- A cream or off-white background with a single muted accent.
- A purple-to-blue gradient, on the background or on the headline text.
- Grey text on a coloured background.
- Every element at the same low contrast, so nothing is first.

## Decoration and motion

- Every corner rounded by the same amount; every card with the same soft shadow.
- An emoji or a generic line icon standing in for each idea.
- Each section fading in as it scrolls into view.
- A hover effect on things that are not links.

## Copy

- A headline that could sit on any company's page ("Welcome to …", "Built for the way you work").
- Three feature titles that are one adjective each.
- Testimonials, numbers or customer names that nobody supplied.
- Placeholder text left in the page.
